Klaper

Bikin video pendek dari satu topik: ide, narasi, suara, animasi.

Pengaturan: hubungkan Google AI Studio

Kunci API dipakai untuk menulis ide, narasi, kode animasi, dan membuat suara. Kunci hanya disimpan di browser ini dan dikirim langsung ke Google. Ambil kunci gratis di aistudio.google.com/apikey.

Nama model bisa berubah. Kalau muncul error model tidak ditemukan, cek daftar terbaru di dokumentasi Gemini API lalu ganti di sini. Halaman ini harus dibuka dari hosting sendiri (Vercel atau GitHub Pages) supaya bisa menghubungi Google.

Tulis narasinya

Pilih satu ide di langkah 1 dulu. AI akan memecahnya jadi scene pendek yang bisa kamu edit.

Cara manual: salin prompt, tempel jawaban

Langkah 3 dari 5

Buat suaranya

Setiap scene dibacakan satu per satu, lalu durasi scene menyesuaikan panjang suara. Langkah ini boleh dilewati kalau kamu mau menambah suara sendiri nanti.

Punya rekaman sendiri? Unggah audio utuh

Durasi semua scene akan disesuaikan dengan panjang rekaman.

Langkah 4 dari 5

Buat animasinya

AI menulis kode gambar untuk setiap scene. Scene tanpa kode memakai animasi bawaan, jadi langkah ini boleh dilewati. Kode dari AI dijalankan di halaman ini, jadi tempel hanya jawaban yang kamu minta sendiri.

Cara manual: salin prompt, tempel jawaban

Langkah 5 dari 5

Simpan videonya

Ekspor merekam pratinjau secara real-time ke file WebM lengkap dengan suara. Biarkan tab ini terbuka selama merekam.

File proyek menyimpan teks, scene, dan kode. Suara tidak ikut tersimpan, jadi buat ulang di langkah 3 setelah membuka proyek.
